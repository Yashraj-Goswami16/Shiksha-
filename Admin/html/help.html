Administration help

Guidance for managing examinations and users.

How do I create an examination?

Open Create Quiz, enter the assessment details, add questions and select the correct answer for each question.

How do I publish an examination?

Review the assessment details and use the connected publishing workflow when backend support is available.

Where can I view student performance?

Open Analytics to review attempts, average scores and score distribution.

How do I manage accounts?

Use User Management to review the registered accounts and their current status.
